# CLAUDE.md

This file provides guidance to Claude Code when working with this repository.

## What This Is

A configurable fantasy baseball draft assistant. Supports any league format:
- Any team count (8-30)
- Any scoring categories (5x5, 6x6, custom)
- Any roster configuration (standard OF, LF/CF/RF, MI/CI, etc.)
- Snake, auction, or keeper drafts

Two main systems:
1. **Research pipeline** (`research/`) -- gathers and merges player data into `data/ranked_players.json`
2. **Draft-day CLI** (`cli.py` / `draft_helper.py`) -- interactive/non-interactive draft tracking and recommendations

## First-Time Setup

If `config/derived_config.json` doesn't exist, guide the user through:
1. Run `python setup.py` for league configuration
2. Help import player data (CSV, screenshots, or web fetch)
3. Run `python research/build_rankings.py` to generate rankings
4. Optionally generate `research/strategic_adjustments.json` via research prompts

Check for available MCP tools at the start:
- **Perplexity MCP available**: Auto-research positional scarcity, sleepers/busts, player news
- **No research tools**: Prompt targeted questions and build adjustments from user answers
- **Always possible**: Generate rank adjustments from projection math (no external tools needed)

## Commands

```bash
# Initial setup
python setup.py              # Interactive league configuration
python setup.py --derive     # Regenerate derived config from existing league_config

# Import data
python import_data.py --csv projections.csv    # Import from CSV
python import_data.py --rankings rankings.json  # Import rankings JSON

# Build pipeline
python research/build_rankings.py   # Generate ranked_players.json
python research/verify_rankings.py  # Validate the deliverable

# Draft day
python cli.py                       # Interactive CLI
python draft_helper.py init 6       # Non-interactive: set draft position
python draft_helper.py rec          # Get recommendation
python draft_cheat_sheet.py         # Round-by-round cheat sheet
python draft_cheat_sheet.py gameplan --position 6  # Opening gameplan
```

## Architecture

### Three-Layer Config

```
Layer 1: config/league_config.json     -- user provides via setup.py
Layer 2: config/derived_config.json    -- generated by setup.py from Layer 1
Layer 3: data/raw/*.json               -- user provides (rankings + projections)
         research/strategic_adjustments.json  -- user provides or Claude Code generates
```

### Data Flow

```
Rankings JSON --> build_rankings.py --> data/ranked_players.json --> cli.py / draft_helper.py
Projections CSV/JSON -+
SV+H data (optional) -+
OF mappings (optional) -+
Strategic adjustments (optional) -+
```

### Agent System (runtime)

The recommendation engine uses three agents via `Orchestrator`:
- `RosterTrackerAgent` -- analyzes roster state, needs, category balance
- `BoardManagerAgent` -- tracks available player pool and positional scarcity
- `ValueAnalystAgent` -- scores candidates using weighted composite

All agents read their constants from `DerivedConfig` (no hardcoded values).

### Key Model: Player

`models/player.py` -- central data structure with name, team, positions, rank, tier, projected_stats, notes, and draft-state fields.

## Draft-Day Workflow (Claude Code Mobile)

`draft_helper.py` is a non-interactive script for live draft use:

```bash
python draft_helper.py init 6              # Set draft position
python draft_helper.py pick "Player1" "Player2"  # Record opponent picks
python draft_helper.py me "Soto"           # Record my pick
python draft_helper.py rec                 # Get recommendation
python draft_helper.py status              # Quick summary
python draft_helper.py resume              # Full context for new session
```

### Screenshot Workflow

User sends draft board screenshots. Claude Code:
1. Reads screenshot, extracts player names
2. Runs `pick` and `round` commands
3. Runs `rec` to get recommendation
4. Reports the pick to user

### Session Management

Restart sessions every ~8-10 rounds. Use `resume` command to restore full context.
All state persists to `data/draft_state.json`.
